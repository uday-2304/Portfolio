A modern, responsive personal portfolio website showcasing my journey as a B.Tech Information Technology student at IIIT Lucknow. This platform highlights my technical skills, competitive programming achievements, and key projects across Full-Stack (MERN) and Blockchain development.

---

## 🌟 What This Application Provides

This portfolio serves as an interactive resume and central hub for my professional identity:

*   **Interactive Project Showcase:** Deep dives into major builds including **TollXstream** (decentralized toll payments), **eScout** (MERN-based esports scouting), and **Jarvis** (AI assistant).
*   **Skills Matrix:** Visual representation of proficiencies in the MERN stack, Solidity, C++, and Python, alongside my active competitive programming profiles (LeetCode & CodeChef).
*   **Experience & Achievements:** Dedicated sections highlighting hackathon milestones (Hackofiesta 6.0 & 6.1) and leadership roles in campus organizations like the Axios Technical Club, E-Cell, and Utkrisht.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing, ensuring a seamless experience for engineering recruiters.

---

## 🗺️ Page Architecture & Navigation

*   **Home / Hero:** High-impact introduction, current academic status, and primary call-to-action (resume download / contact).
*   **About Me:** Background details, education timeline at IIIT Lucknow, and long-term career goals.
*   **Projects:** Filterable grid of technical projects with links to live demos and GitHub repositories.
*   **Experience:** Timeline of club involvement and hackathon participation.
*   **Contact:** Direct messaging form and links to LinkedIn, GitHub, and email.

---

## 💻 Tech Stack

*   **Frontend:** React.js
*   **Styling:** Tailwind CSS, Framer Motion (for smooth UI animations)
*   **Deployment:** Vercel
